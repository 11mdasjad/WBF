# WBF reference audit

Audit date: 25 October 2026. Source: https://wbfngo.org/. Read-only HTTP inspection of the public sitemap, HTML, shared navigation, public content feeds and client scripts. No registration, contact, application, donation or purchase was submitted. No protected records were accessed. This is a content/behavior audit, not a claim of browser/device verification.

## Findings that control the build

- The eight real focus areas differ from the supplied visual mockup. Preserve the live categories in `reference-data.json`.
- `/profile/` is the public organization brochure. Member access is `/user/`; `/admin/` serves an unauthenticated application shell. Preserve both meanings.
- Public metrics conflict: home lists 105k beneficiaries, 170 programs, 1000k volunteers and 29 states; impact uses other figures and labels some as archive-theme values. Donation claims include unsupported matching and a rating. Do not present these as verified operational figures.
- Contact information is published on `/contact/` and `/profile/`; the shared options feed still has a placeholder address. Use the concrete page address, noting source provenance.
- Source contact code simulates successful submission with a timer. The replica must actually persist messages and report real outcomes.
- Three blog entries, three job entries and eighteen event records were observed in the public feeds. Static careers HTML says zero openings before hydration. These are source records, not proof jobs remain open.
- The store is a discovered part of the site: catalog, product details, cart, shipping/billing and payment flows. A faithful route inventory must include it.
- Reports and financials pages are placeholders; no annual report links are published there. Brochure and eight license/certificate PDFs are publicly linked and returned HTTP 200. Sixteen policy PDF links are present but all returned HTTP 404; do not expose them as working downloads.
- No reusable license for reference photos, logos, PDFs or partner marks was established. Do not mirror them without authorization. Direct source document links preserve access. Use separately licensed imagery with explicit illustrative context.
- No private dashboard capability, email delivery, tax eligibility, current certificate validity, merchant configuration, or payment success was verified. Implemented backend behavior is an explicit design assumption rather than an observed private replica.

## Navigation, layout and behavior

The global chrome is loaded from HTML fragments. Desktop navigation supports dropdowns for About, Our Work, Get Involved and Resources; Events and Store are primary links. A donation CTA, account menu, search, user/admin access and registration links are present. Mobile navigation toggles a sheet and expandable groups; Escape and outside click dismiss it. Search combines static page content with public products, posts, campaigns and events; arrow keys and Enter select results. Footer includes social, resource, policy, user and admin links. Header/footer source assets and social destinations are enumerated in the JSON inventory.

The public site uses green and white with image-led heroes, program grids, resource panels, and responsive CSS. Home adds a three-image slider, mission, program promotions, focus links, approach, blog/events feeds, gallery, reels and donation/registration CTAs. The stylesheet contains mobile/tablet breakpoints from 390px through 1120px and a reduced-motion media query. Mobile touch behavior, actual responsive rendering, contrast and keyboard coverage remain unverified by this HTTP-only audit.

## Content and asset decisions

`reference-data.json` contains short rewritten program descriptions, factual team names/roles, concise blog/career summaries, event dates and venues, observed product prices, source links, and document URLs with HTTP status. It intentionally omits original prose, merchant settings and image copies. Team biographies and social profile links were not published in the audited team page. The Saad Khan image alt text says Director while the visible title says Media & Comm. Head; prefer the visible title pending organization confirmation.

About lists trust registration 1018 dated 1 June 2015, PAN AAATW3827H, TAN DELW07736B, Darpan DL/2018/0191071 and other identifiers. These are publicly asserted identifiers, not independently validated credentials. Avoid asserting current tax eligibility from them. The team page lists Saad Khan, Farha Naaz, Shivam Mehrotra and Zahid Khan. No biography details should be invented.
